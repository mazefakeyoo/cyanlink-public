# cyanlink-public

[English](README.md) | [简体中文](README.zh-CN.md)

Public distribution repository for **CyanLink**: the one-click relay install script.
frp binaries are downloaded directly from the [official frp releases](https://github.com/fatedier/frp/releases) by default — no binaries need to be hosted here.

## Resources

| Resource | URL |
|---|---|
| Install script | `https://raw.githubusercontent.com/mazefakeyoo/cyanlink-public/main/scripts/install-relay.sh` |
| frp binaries (default source) | `https://github.com/fatedier/frp/releases/download/v<version>/frp_<version>_linux_<arch>.tar.gz` |
| Backup mirror (v0.61.2, amd64/arm64) | [Releases](https://github.com/mazefakeyoo/cyanlink-public/releases) — unmodified official packages |

## Install a relay manually

On the target server (Ubuntu/Debian, x86_64 or arm64, root required):

```bash
curl -fsSL https://raw.githubusercontent.com/mazefakeyoo/cyanlink-public/main/scripts/install-relay.sh \
  | bash -s -- --bind-port 7000 --frps-token <your-frps-token>
```

### Parameters

| Parameter | Required | Description |
|---|---|---|
| `--bind-port` | yes | frps control port to listen on (firewall/security group must allow it) |
| `--frps-token` | yes | frp auth token; must match the token generated by your CyanLink instance |
| `--frp-dl-base` | no | Custom download base following the layout `<base>/v<version>/<file>`; defaults to the official frp GitHub release |
| `--frp-version` | no | frp version to install (default `0.61.2`) |

## How it works

- The script only installs frps and starts it as a systemd unit (`cyanlink-relay`, config at `/etc/cyanlink/frps.toml`). It performs **no callbacks** — CyanLink decides "installed / online" by actively probing the control port (`bind_port`) and verifying the auth token.
- Download order: `<frp-dl-base>` first, automatic fallback to the official frp GitHub release. If frps is already installed, the download is skipped.
- **One relay instance per server**: the script uses a fixed config path and unit name. Re-running with different parameters rewrites the config and restarts the service (idempotent reinstall), so config changes take effect without manual cleanup.
- Root and `curl` are the only prerequisites; no other dependencies.
